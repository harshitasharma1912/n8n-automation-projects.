# 📧 Gmail to Google Sheets Automation

## 📌 Project Overview

This project automates the process of retrieving Gmail data and storing the required information in Google Sheets using n8n.

The automation eliminates repetitive manual data entry and provides a simple way to organize email information in a structured spreadsheet.

## ⚙️ Workflow

### Workflow Flow

Manual Trigger → Gmail → Google Sheets

The workflow retrieves email data from Gmail, processes the required information, and appends it to a Google Sheet.

## 🛠️ Technologies Used

- n8n
- Gmail
- Google Sheets
- Google APIs

## ✨ Key Features

- Automatically retrieves Gmail data
- Stores email information in Google Sheets
- Reduces repetitive manual data entry
- Organizes email data in a structured format
- Demonstrates integration between Gmail and Google Sheets using n8n
