# 📧 Email Tracker Automation

## 📌 Project Overview

This project automates the process of retrieving emails from Gmail and storing the email information in Google Sheets using n8n.

The automation helps organize email data in a structured spreadsheet and reduces repetitive manual work.

## ⚙️ Workflow

### Workflow Flow

Manual Trigger → Get Many Messages → Edit Fields → Append Row in Google Sheets

The workflow retrieves email messages from Gmail, extracts the required information, processes the data, and appends it to a Google Sheet.

## 🛠️ Technologies Used

* n8n
* Gmail
* Google Sheets
* Google APIs

## ✨ Key Features

* Retrieves multiple email messages from Gmail
* Extracts required email information
* Processes email data using n8n
* Stores email information in Google Sheets
* Reduces manual data entry
* Demonstrates Gmail and Google Sheets integration
